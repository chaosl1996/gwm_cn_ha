| 功能 | 说明 |
|---|---|

| 🔐 **远程锁车/解锁** | lock 实体,云端下发锁控指令 |
| 🔊 **找车/车控按钮** | 鸣笛、闪灯、鸣笛+闪灯、关全车窗、关天窗、远程启动/熄火 |

**支持车型**(理论上所有 GWM 中国区在售车型均可):
- TANK 300 / 300 HEV / 330 / 400 / 500 / 700

## 🚀 安装

### 方式 A:HACS(推荐,可自动更新)

1. **打开 HACS → 集成 → ⋮ 右上角菜单 → 自定义存储库**
2. 填入:
   - **存储库 URL**:`https://github.com/chaosl1996/gwm_cn_ha`
   - **类别**: 集成
3. 点击「添加」
4. 在 HACS 里搜索 **GWM China (Tank/Haval)** → 点击「下载」(或「下载最新版本」)
5. **重启 Home Assistant**

### 方式 B:手动拷贝

1. 下载 [Latest Release](https://github.com/chaosl1996/gwm_cn_ha/releases/latest) 的 `gwm_cn.zip`
2. 解压后把 `custom_components/gwm_cn/` 整个目录拷贝到你 HA 的 `custom_components/` 目录(通常在 `/config/custom_components/`)
3. **重启 Home Assistant**

## ⚙️ 配置

### 前置:准备一个专用小号

> ⚠️ **强烈建议注册一个新的 GWM 账号专门给本集成使用,不要用手机上登录的主账号。**
> 同一账号被 APP 和集成同时使用会互相顶号,导致 refresh token 失效。
> 新账号需先在坦克 APP 登录一次(完成首次验证、能看到车辆),再登出手机。

### 添加集成(短信登录,无需抓包)

1. **设置 → 设备与服务 → 添加集成**,搜索「**GWM China**」
2. 输入小号的**手机号** → 接收短信**验证码** → 账号下有多辆车时**选择车辆**
3. 完成后自动创建设备;集成会**自动刷新 token**,无需任何手动维护
4. 确认车况读取正常后,进入 **集成 → 配置(选项)**:
   - **轮询间隔**:默认 60 秒(30-3600 可调)
   - **启用远程控制**:默认关。打开后才有 锁车/空调/远程启动/除霜 等车控能力

> 首次登录若提示「触发风控」,先在坦克 APP 里登录一次该小号完成验证,再回来重试。

### 旧版 token 条目怎么办?

v0.1.x 的抓包 token 条目会自动迁移并继续工作,但 token 约 7 天失效且无法自动续期,
**建议删除后重新添加走短信登录**。旧条目没有远控能力。

## 📋 完整实体清单

### 设备追踪器(1 个)

| 实体 ID | 名称 | 说明 |
|---|---|---|
| `device_tracker.gwm_xxx_vehicle_location` | 车辆位置 | GPS 定位,实体图片为集成 logo,带里程/油量/续航/引擎状态/门锁等属性 |

### 传感器(约 19 个)

| 类型 | 名称 | 单位 | 说明 |
|---|---|---|---|
| 🟢 油电 | **剩余油量** | L | `remainOil` |
| 🟢 油电 | **综合续航** | km | `preMileage`,与 APP「续航里程」一致 |
| 🟢 油电 | **油表格数** | 格 | `oilQty`,0-8 格蓝条 |
| 🟢 油电 | **行驶总里程** | km | `mileage`,与 APP「行驶总里程」一致 |
| 🌡️ 温度 | **车厢温度** | ℃ | `cbnTemp`,远程空调的当前温度来源 |
| 🚙 动力 | **引擎状态 / 档位 / 电源状态** | - | 熄火 / P 档 / 下电等 |
| 🛞 轮胎 | **4 胎压 + 4 胎温** | kPa / ℃ | 与 APP 四角卡片对应 |
| 🔵 诊断·默认隐藏 | **混动动力电池 / 纯电续航 / 平均油耗 / 平均能耗 / 动力电池电压** | - | 混动车专属,**纯燃油车恒为未知,已默认禁用**,可在实体设置里手动开启 |
| 🔵 诊断 | **最后更新 / GPS 开关** | - | 数据采集时间等 |

### 二元传感器(约 29 个)

| 分类 | 名称 | 说明 |
|---|---|---|
| 🔒 锁 | **车门锁** | on=未锁, off=已锁(只读状态;可控锁在下方 lock 实体) |
| 🚪 门(6) | 左/右/前/后门 + 后备箱 + 引擎盖 | on=开 |
| 🪟 门窗(5) | 4 车窗 + 天窗 | 关=`"1"`(天窗=`"3"`),其余值=开 |
| ❄️ 空调(5) | 空调 / 自动模式 / 前后除霜 / 风挡加热 | on=激活 |
| 💡 灯光(2) | 近光灯 / 远光灯 | 熄火时显示未知 |
| 🔥 座椅(7) | 方向盘加热 + 主/副驾加热/通风 + 后排加热 | on=开 |
| ⚠️ 报警(6) | 4 胎压异常 + 防盗 + 油量低 | on=异常 |

### 锁 / 按钮 / 空调(远控,需开启「启用远程控制」+ 短信登录条目)

| 实体 | 说明 |
|---|---|
| 🔐 `lock.xxx_车门锁控制` | 远程锁车 / 解锁 |
| ❄️ `climate.xxx_远程空调` | 17-31℃,`allowStartEng=1` 自动允许启动发动机(燃油车预热预冷) |
| 🔘 鸣笛找车 / 闪灯找车 / 鸣笛+闪灯 | 默认启用 |
| 🔘 关闭全车窗 / 关闭天窗 | 默认启用(忘关窗补救) |
| 🔘 远程启动(15分钟) / 远程熄火 | 默认启用,请确保停车通风安全 |
| 🔘 前后除霜开/关、方向盘加热开/关、主/副驾座椅加热/通风开/关 | 默认隐藏,需要时在实体设置里开启 |

远控命令经 GWM 云端转发到车,执行有数秒延迟;鸣笛/闪灯走 `remote-ctrl/timely` 即时通道,其余走 `T5/sendCmd`。

## 🔄 服务

| 服务名 | 作用 |
|---|---|
| `gwm_cn.refresh` | 立即从 GWM 中国网关拉一次最新车辆状态(忽略 coordinator 的缓存) |

可以在自动化里调用,比如:
- 车门开了 + 你离家 → 立即刷一次
- 每天定时刷(默认 coordinator 是 5 分钟 poll 一次)

## 🔧 工作原理

```
        ┌──────────────────────┐
        │   坦克 APP (手机)    │
        │  ↓ (HTTPS, 带签名)   │
        │ apgdm.gwmcloudcn.com │
        └──────────────────────┘
                    ↑
        ┌─────────────┴──────────────┐
        │   华为云 WAF (防爬虫层)    │
        └─────────────┬──────────────┘
                    ↑
        ┌─────────────┴──────────────┐
        │   GWM China HA Integration │
        │  ↓ 携带 accessToken +      │
        │  HWWAFSESID cookie 直查    │
        │  GET /getLastStatus?vin=   │
        └────────────────────────────┘
```

**登录链路(v0.2.0+)**
协议逆向参考 [moryoav/ha-gwm-ev](https://github.com/moryoav/ha-gwm-ev) 的成果
(其已对 Tank 300 Hi4-T 中国区 BeanTech 平台实测验证),链路为三个服务串联:

```
手机号+短信验证码 ──► G-App (gapp-api.gwmapp-h.com)
                       │ gToken / ssoToken(到期自动 refresh)
        ┌──────────────┴──────────────┐
        ▼                             ▼
   BeanTech SSO                    AutoAI 登录
(gw-app-gateway.gwmapp-h.com)   (tsp/v1/proxy/navinfo)
   │ accessToken                    │ tokenId
   ▼                             ▼
 车况查询 getLastStatus          车况查询请求头
 车控 T5/sendCmd / timely
```

请求签名(`bt-auth-sign` / `Sign` / `sign`)与 `G_A()` AES 信封加密均已实现,
token 过期由集成用 `gRefreshToken` 自动续期并持久化,无需人工干预。
